# Lagao.shop Website Source

## Core Rules

- Mobile-first layout
- Plants must remain centered
- Avoid cropped leaves
- Rounded modern UI
- Warm earthy color palette
- Large readable spacing
- Premium but natural feeling

## Navbar Rules

- Logo must remain readable on mobile
- Balanced spacing
- No overcrowding
- Sticky navigation preferred

## Product Card Rules

- Uniform image sizing
- Consistent padding
- Clean shadows
- Minimal clutter

## Image Rules

- Matte black nursery pots
- Realistic plant textures
- Soft cinematic lighting
- Consistent background system

## Website Goal

A premium plant brand that feels rooted, cinematic, warm, and real — not generic dropshipping.
