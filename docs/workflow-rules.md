# Lagao.shop Workflow Rules

## Main Rule

Never directly destroy a working stable version.

## Before Major Changes

- Commit current stable state
- Test changes carefully
- Verify mobile responsiveness
- Verify plant image alignment

## Commit Rules

Use clear commit names.

Good examples:
- Fix mobile navbar spacing
- Improve hero image scaling
- Replace incorrect plant assets

Avoid:
- fix
- update
- finalfinal
- test

## Image Rules

- Never crop important leaves
- Maintain centered compositions
- Preserve breathing space
- Use consistent lighting systems

## Website Philosophy

The website should feel:
- warm
- breathable
- cinematic
- premium
- grounded
- emotionally calm
